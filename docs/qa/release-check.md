Это не утверждение, что проверен реальный товар с более чем 20 предложениями. Такие большие наборы проверены детерминированными тестами; для расширенного пилота нужна дополнительная живая выборка.

Отчёты: [основная матрица](kaspi-live.json), [дополнительные товары](kaspi-extra.json), [пагинация](kaspi-pagination.json). Время в JSON — UTC. Сохранены только публичные поля товара и анонимные суммы; данные продавцов не сохранялись.

Ограничения: запросы последовательные, снимок не атомарный. Арифметическая сверка API не равна подтверждению суммы в checkout Kaspi. Сбой/смена формата/неполный список/изменение количества/неверный город и товар проверены тестами на фикстурах, не искусственным воздействием на Kaspi. Это проверка конкретной выборки, не гарантия работы для всех категорий.

## 4. Аккаунты и эксплуатация

- Добавлены подтверждение почты, повторная отправка, восстановление пароля и одноразовые ссылки с истечением срока. Неподтверждённые аккаунты изолированы от расчётов и инструментов.
- При смене пароля все сессии отзываются; повторное использование ссылки невозможно. Ответ на запрос восстановления одинаков для известного/неизвестного email; отправка выполняется после ответа.
- Локальная почта работает через файлы, а не настоящую доставку. Resend подготовлен и протестирован с mock-ответом. Production запрещает локальную почту и требует HTTPS-origin и почтовые настройки.
- Добавлены серверная запись ознакомления с обработкой данных, страница фактической обработки данных и удаление аккаунта с проверкой пароля.
- Online backup SQLite создан на рабочей локальной базе; изолированное восстановление, миграция схемы и integrity_check прошли. Рабочая база не заменялась.
- Dockerfile, постоянный volume, Caddy, healthcheck, ежедневный backup-контейнер, обслуживание и ротация журналов подготовлены. Compose-конфигурация валидна. Docker Engine не запущен: реальная сборка/запуск контейнеров и выдача сертификата не подтверждены.
- Добавлены защитные HTTP-заголовки, ограничения тела на reverse proxy и кодированные JSON-события ошибок без тел запросов и секретов. Внешний мониторинг/уведомления и внешнее хранилище копий потребуют инфраструктуры.

## 5. Пользовательский путь

В браузере пройден путь: главная → регистрация с ознакомлением → локальное письмо → подтверждение email → Kaspi-ссылка → 9 предложений → вторая страница таблицы → применение медианы → калькулятор → рекомендация → CSV → сохранение → повторное открытие → выход. Статистика не изменилась от переключения страниц. Цена 23 242 ₸ и расчётная прибыль 5 000 ₸ сохранились после повторного открытия. Цена рекомендации выше медианы — интерфейс явно сообщает об этом.

[Скачанный учебный CSV](calculation-sample.csv). [Скриншот проверенного расчёта](workspace-e2e.jpg). HTTP-сценарии отдельно проверяют два аккаунта, CSRF, смену пароля, отзыв сессий и удаление собственных данных. В браузере проверены ссылка «Забыли пароль?», запрос письма и открытие формы нового пароля. В форме исправлено чтение фрагмента ссылки при повторном эффекте React в dev-режиме.

Форма восстановления проверена на ширинах 375, 768, 1024 и 1440: scrollWidth не превышает clientWidth. Ранее существующие страницы сохраняют свой Bento-дизайн. Черновики ИИ не публикуются автоматически; ссылка на обработку данных есть рядом с запуском.
